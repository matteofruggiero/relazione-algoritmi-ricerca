# relazione-algoritmi-ricerca


Il workflow KNIME è stato sviluppato e testato in ambiente locale.
Per l’esecuzione su un altro PC potrebbe essere necessario aggiornare i percorsi dei file CSV
e del file Python nei nodi del workflow.

La cartella dataset contiene i file di input utilizzati per i test.
La cartella output_esempio contiene i risultati già generati.
La cartella screenshot_workflow contiene immagini del workflow e dei grafici prodotti.
